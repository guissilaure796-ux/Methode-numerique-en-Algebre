# Méthodes numériques en Algèbre en Python

## Recherche de racines
- dichotomie.py : recherche de racine par dichotomie
- balayage.py : localisation des racines par balayage
- newton.py : méthode de Newton
- newton_raphson.py : méthode de Newton-Raphson (système non linéaire)

## Interpolation polynomiale
- lagrange.py : interpolation de Lagrange
- vandermonde.py : interpolation par la matrice de Vandermonde
- aitken.py : schéma d'Aitken

## Systèmes linéaires : méthodes directes
- crout.py : décomposition de Crout (A = LU)
- cholesky.py : décomposition de Cholesky (A = LL^T)
- gauss_jordan.py : méthode de Gauss-Jordan

## Systèmes linéaires : méthodes itératives
- jacobi.py : méthode de Jacobi
- gauss_seidel.py : méthode de Gauss-Seidel
- richardson.py : méthode de Richardson

Exécution : python nom_du_fichier.py
